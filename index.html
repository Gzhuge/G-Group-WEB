功能详情IN DETAIL

六大模块逐一介绍。带「看第 X 幕」的，点一下直接跳到上面那段动画的对应场景。

01 · ENGINE

群聊引擎

  • 五种发言模式：全员必须回复 / 全员选择回复 / 自由讨论（无限轮询）/ 按需发言 / 群主意愿。
  • 两种回复节奏：顺序（逐个接话，话题连贯）或同时（并行回复，互不等待）。
  • 随时停止：发送键可中止当前正在输入的所有成员，已生成的半截内容保留。
  • @ 提及：任何模式下被 @ 的成员强制优先发言，兼容全角＠。
02 · MEMORY

记忆与上下文

  • 群公共记忆：整个群压缩后共用同一份上下文，所有成员看到的世界一致。
  • 成员个人记忆：被 @、主动回复、被分配的任务自动归档，仅该成员可见。
  • 触发方式：不启用 / 自动（超阈值自动总结）/ 手动（在 Token 面板触发）；阈值与保留条数均可调。
  • Token 面板：实时估算群聊与每个成员的 Token 占用，超标红色提示。
03 · PROTOCOL

供应商与模型

  • 支持协议：OpenAI 兼容 / Anthropic Claude / Google Gemini。
  • 模型能力可勾选：思考档位、视觉、原生联网、视频、工具调用。
  • 思考档位三协议适配：中文档（低/中/高）或数字档（如 8192）皆可。
  • 一键拉取模型列表；端点支持「自动补全」或「手填完整 URL」。
04 · SEARCH

联网搜索

  • 基于 Bing 搜索，无需申请 API Key，在输入栏按消息开关。
05 · AESTHETICS

外观与体验

  • 亮色「暖纸」/ 暗色「墨夜」两套配色，跟随系统或手动指定。
  • 无渐变、无高饱和色，以暖灰纸面 + 墨黑主色构建克制层级。
  • 流畅动效：多档弹簧规格（回弹/阻尼/果冻弹），消息入场、列表错峰浮现、底栏跟手吸附。
06 · PRIVACY

隐私与数据

  • 全部数据存于手机本地（Room 数据库），不上传云端、不做账号体系。
  • 可一键清除所有数据。

常见问题FAQ

常见问题，逐条解答。

问

需要自己准备 API Key 吗？

需要。应用只负责对话与编排，模型由你自己的供应商账号提供。

问

支持国内中转站吗？

支持，任何兼容 OpenAI 格式的接口都能接。

问

数据会上传吗？

不会。聊天与配置都存在本地，只有调用模型接口时才会把你的对话发给该供应商。

问

能同时用不同厂商的模型吗？

可以，每个成员可绑定不同模型，也可整群统一一个模型。

问

换手机怎么迁移？

目前需手动备份，暂未内置导出功能。

关于 G-AI

ABOUT & QUICK START

01 · 什么是 G-AI

G-AI 是一款 Android 原生的多供应商、多角色 AI 群聊客户端：你创建一个群，把多个 AI 人物卡拉进来，它们在同一份聊天记录里互相接话、讨论、互相补充——而不是单对单问答。

支持 OpenAI / Claude / Gemini 三协议，数据全部存在手机本地，不上云、无账号。

02 · 快速上手

  • 1下载安装下载 APK，支持 Android 8.0 及以上，安装包仅 12MB
  • 2配置 API填入 Base URL 与 Key，兼容所有 OpenAI 格式的中转站
  • 3创建人物卡给每个 AI 设置头像、名字、人设与模型，拉进群里
  • 4开始群聊选择发言模式，发送第一条消息

03 · 核心特性

  • 协多供应商接入OpenAI / Claude / Gemini 三协议原生适配
  • 式五种发言模式从全员回复到被 @ 才回，按场景切换
  • 忆双层记忆系统群公共记忆 + 成员私有记忆，独立压缩
  • 锁隐私与本地存储Room 数据库本地存储，可一键清除所有数据
